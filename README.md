# Dynamic Bakery Website Using PHP

A fully dynamic and responsive bakery website built using **PHP, HTML, CSS, and JavaScript**. This project demonstrates a complete bakery management system with a front-end for customers and a backend for managing products.

## Features

- Fully dynamic website using **PHP and MySQL**
- Responsive design for desktop and mobile
- Smooth animations
- Multiple pages:  
  - Home/Dashboard  
  - About  
  - Products (Cakes, Biscuits, Sweets)  
  - Contact Us  
  - Feedback
- CRUD operations for managing bakery items
- Interactive forms with validation
- Organized folder structure for assets, scripts, and CRUD operations

## Technologies Used

- **PHP** – Backend logic
- **MySQL** – Database management
- **HTML5 & CSS3** – Structure and styling
- **JavaScript & jQuery** – Animations and DOM manipulation
- **Bootstrap** – Responsive layout
- **Font Awesome** – Icons
